# Dirty Hands

Dirty Hands: The Price of Staying Alive
A Memoir of Survival, Struggle, and Resilience

This repository contains a simple sales landing page for the memoir Dirty Hands. It is designed to be a clean starter for direct selling or as a foundation for a custom storefront.

## Files
- `index.html` — landing page
- `styles.css` — styling

## Customization
Replace the placeholder purchase links in `index.html` with your actual Gumroad, Payhip, Stripe, or Amazon KDP URLs.

## Quick launch idea
1. Update the CTA links.
2. Add your author bio and press image.
3. Publish the site on GitHub Pages, Netlify, or Vercel.
4. Share the link on social media and email.

## Recommended sales setup
- Ebook: $4.99–$6.99
- Paperback: $14.99–$17.99
- Direct selling: Gumroad or Payhip
- Wider availability: Amazon KDP

## Book positioning
Dirty Hands is a raw and unforgettable memoir about survival, struggle, and the quiet strength it takes to keep moving when life knocks you down.
